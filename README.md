# Лабораторная работа №3 — Доска публикаций

## Запуск
Откройте `index.html` в современном браузере (Chrome, Firefox, Edge).
Требуется интернет для запросов к jsonplaceholder.typicode.com.

## Реализованные функции
- Кнопка «Загрузить публикации»: GET-запрос через `fetch` + `async/await`,
  проверка `response.ok`, вывод 5 публикаций (заголовок и текст) через DOM (`textContent`).
- Форма создания: валидация (пустые поля и пробелы), `preventDefault`,
  POST-запрос с JSON и заголовком `Content-Type: application/json`.
- Вывод ID и заголовка из ответа, сообщение об успехе, новая запись появляется в списке.
- Состояние загрузки/отправки: сообщения, блокировка кнопок, повторная активация в `finally`.
- Обработка ошибок: `response.ok`, `try/catch/finally`, понятные сообщения.

## Результаты проверки
- «Загрузить публикации» → 5 записей с заголовками и текстом.
- Пустые поля или пробелы → ошибка на странице, запрос не отправляется.
- Корректные данные → успешный ответ (HTTP 201), публикация появляется.
- Адрес с ошибкой (404) → сообщение об ошибке, кнопка снова активна.
